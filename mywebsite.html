My Skills

  • HTML: HTML stands for HyperText Markup Language. It creates the structure of a webpage using elements such as headings, paragraphs, links, images, lists, and forms.
  • CSS: CSS stands for Cascading Style Sheets. It controls the appearance of a webpage, including colors, fonts, spacing, borders, and layout.
  • Git: Git is a version control system that tracks changes in my code. I can save versions of my work using commits and review earlier changes.
  • GitHub: GitHub is an online platform where I can store my Git repositories, back up my code, share my work, and collaborate with other developers.
  • JavaScript: JavaScript is a programming language that adds interactivity to websites. I am currently learning its basic concepts and practicing how to use them.

I am continuing to strengthen these skills through regular practice, coursework, and my portfolio assignment.
