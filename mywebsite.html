My Technical Skills

The following technologies and tools are part of my current learning journey. My skills are still developing, and I continue to practice and improve them.

HTML

HTML stands for HyperText Markup Language. It provides the structure and meaning of web content. I use HTML elements to organize headings, paragraphs, links, lists, and different sections of a webpage.

I am practicing how to structure webpages clearly, use semantic elements, organize content into sections, create navigation links, and write readable HTML code.

CSS

CSS stands for Cascading Style Sheets. It controls the visual presentation of web content, including colors, fonts, spacing, borders, alignment, and page layout.

I am learning how HTML and CSS work together to create webpages that are organized, attractive, and easier for visitors to read and navigate.

JavaScript

JavaScript is a programming language that can add behavior and interactivity to websites. It can respond to user actions, process data, validate forms, and update webpage content.

I am currently learning JavaScript fundamentals, including variables, functions, arrays, conditions, and loops. I practice these topics through programming exercises to improve my understanding of logic and how programs execute.

Git

Git is a version control system that records changes to files over time. It helps developers maintain a history of their work, review changes, and return to earlier versions when needed.

I am learning to use Git commands such as git add, git commit, and git push as part of managing my portfolio development.

GitHub

GitHub is an online platform for hosting Git repositories. It allows developers to store source code, share projects, track development work, and collaborate with others.

I use GitHub for my portfolio repository so I can maintain my work online and record updates throughout the semester.

Problem-Solving Skills

Problem-solving is an important part of programming. It involves understanding a problem, breaking it into smaller tasks, identifying possible solutions, writing logical steps, and checking whether the solution works.

I am developing these skills by practicing programming questions, tracing code step by step, understanding errors, and comparing different ways to solve a problem.

Communication and Teamwork

Software developers often work with customers, users, analysts, designers, testers, and other developers. Clear communication helps everyone understand the requirements and work toward the same objectives.

As a student, I want to improve my communication, technical explanation, documentation, and teamwork skills alongside my programming knowledge.
